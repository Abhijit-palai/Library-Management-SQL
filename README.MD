# 📚 Library Database Analysis using SQL

A complete SQL project that demonstrates the design, implementation, and analysis of a **Library Management System**. The project focuses on creating a relational database, establishing relationships between tables using primary and foreign keys, and solving real-world business questions using SQL.

---

## 📌 Project Overview

The Library Database Analysis project simulates the operations of a library management system. It includes designing a normalized relational database, importing data, and writing SQL queries to answer business-oriented analytical questions.

The project demonstrates practical usage of SQL for database design, data retrieval, aggregation, filtering, and reporting.

---

## 🎯 Objectives

- Design a relational database for a library management system.
- Create tables with appropriate constraints and relationships.
- Import and manage library datasets.
- Perform analytical queries to extract meaningful insights.
- Demonstrate proficiency in SQL joins, aggregate functions, and filtering techniques.

## 🗂️ Database Schema

The database consists of the following tables:

- tbl_publisher
- tbl_book
- tbl_book_authors
- tbl_library_branch
- tbl_book_copies
- tbl_borrower
- tbl_book_loans

The tables are connected using Primary Keys and Foreign Keys to maintain data integrity.

## 📊 Business Questions Solved

1. Number of copies of **"The Lost Tribe"** available in the **Sharpstown** branch.
2. Number of copies of **"The Lost Tribe"** available in each branch.
3. Borrowers who have not borrowed any books.
4. Books due on **02-03-2018** from the Sharpstown branch with borrower details.
5. Total books loaned from each library branch.
6. Borrowers having more than five books checked out.
7. Stephen King's books available in the Central branch along with available copies.

---

## 📈 Key Findings

- Retrieved the availability of **The Lost Tribe** across library branches.
- Identified borrowers with no active loans.
- Analysed branch-wise book loan distribution.
- Found borrowers with more than five active loans.
- Retrieved Stephen King's books available in the Central branch.
